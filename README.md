# Портфолио / CV

Одностраничный сайт-портфолио, он же онлайн-резюме для откликов на Frontend-вакансии.
React 19 + TypeScript + Vite + Tailwind CSS v4, две темы, два языка (RU/EN), без бэкенда.

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:5173

Другие команды:

```bash
npm run build     # production-сборка в dist/ (с проверкой типов)
npm run preview   # посмотреть собранную версию локально
```

## Что где лежит

Весь текст сайта — в `src/content/`. Компоненты трогать не нужно.

| Файл | Что там |
| --- | --- |
| `src/content/profile.ts` | **Начните отсюда.** Имя, должность, о себе, контакты, ссылка на резюме, ключ формы |
| `src/content/skills.ts` | Группы навыков |
| `src/content/projects.ts` | Проекты: описание, стек, ссылки на демо и код |
| `src/content/experience.ts` | Места работы и образование |
| `src/content/posts.ts` | Статьи блога (можно очистить — секция сама исчезнет) |
| `src/i18n/ui.ts` | Подписи интерфейса (кнопки, заголовки секций) |

Каждая строка контента хранится сразу на двух языках:

```ts
title: { ru: 'Аналитическая панель', en: 'Analytics Dashboard' }
```

## Чек-лист перед публикацией

Контент уже заполнен по `Serhii_Malyskevych_CV.pdf`. Осталось:

- [ ] **Ссылка на GitHub** — `github` в `profile.ts`. Для фронтенда это первое, что открывает рекрутер; в резюме её не было
- [ ] **Даты работы** — `start` / `end` в `experience.ts`. В резюме их нет, сейчас периоды не отображаются
- [ ] **Проекты** — два слота-заглушки в `projects.ts` заменить или удалить; проставить `demoUrl` и `codeUrl` у реальных
- [ ] **Блог** — тексты в `posts.ts` написаны по мотивам резюме, но не вами. Переписать своими словами или очистить массив
- [ ] Подключить форму: см. раздел «Форма обратной связи»
- [ ] Положить в `public/` картинку `og-image.png` (1200×630) для превью в мессенджерах
- [ ] Скриншоты проектов — в `public/projects/`, путь прописать в поле `image`
- [ ] Заменить `Serhii_Malyskevych_CV.pdf` в `public/`, когда обновите резюме

## Форма обратной связи

Форма работает через [Formspree](https://formspree.io) — бесплатный тариф даёт 50 писем в месяц,
свой сервер не нужен.

1. Зарегистрируйтесь и создайте форму.
2. Из адреса вида `https://formspree.io/f/xyzabcd` скопируйте `xyzabcd`.
3. Вставьте в `formspreeId` в `src/content/profile.ts`.

Пока поле пустое, кнопка отправки заблокирована и показывается подсказка.

## Смена фирменного цвета

В `src/index.css` в блоке `@theme` четыре переменные `--color-brand-*`.
Поменяете их — перекрасится весь сайт: кнопки, акценты, градиенты, свечение на первом экране.

## Публикация на GitHub Pages

Деплой настроен через GitHub Actions — пуш в `main` собирает и публикует сайт автоматически.

```bash
git init
git add .
git commit -m "Портфолио: первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/portfolio.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Source → GitHub Actions**.

Через пару минут сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/portfolio/`.

`base: './'` в `vite.config.ts` делает пути к ассетам относительными, поэтому сборка
одинаково работает и в подпапке на GitHub Pages, и в корне на любом другом хостинге.
